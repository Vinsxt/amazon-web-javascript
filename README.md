# Amazon Project — JavaScript

A hands-on learning project following [SuperSimpleDev's JavaScript Tutorial](https://www.youtube.com/watch?v=EerdGm-ehJQ), implementing an Amazon-inspired e-commerce website while documenting my learning process in Notion.

## What I'm Learning

* JavaScript fundamentals, `forEach()`, callbacks, and function refactoring
* ES modules (`import` / `export`) and MVC design pattern
* Object-oriented programming (OOP) and inheritance
* Dynamic HTML generation and external libraries
* Unit testing with Jasmine and testing frameworks
* Backend communication, HTTP requests, `fetch()`, promises, and `async`/`await`
* URL paths, URL parameters, and JSON

## Learning Process

I follow the tutorial step by step, implement the code, and write detailed explanations in Notion to reinforce my understanding and improve knowledge retention.

This project is also part of my learning journey toward backend development with **Node.js and Express.js**, building a strong foundation in JavaScript and how web applications communicate with backend servers.
